Mobile Performance Fix Report

Project: laravel_nuxt_project_ecommerce
Target: Homepage mobile ও desktop PageSpeed performance

লোকাল production build সফল

সমস্যার মূল কারণ

Nuxt configuration-এ ssr: false ছিল। তাই live homepage-এর প্রথম HTML-এ #___nuxt খালি থাকত। Hero content, title এবং image দেখতে browser-কে আগে JavaScript download/execute করে API response-এর জন্য অপেক্ষা করতে হতো। Slow mobile network-এ এটি NO_LCP বা খারাপ LCP-এর বড় কারণ।

যে পরিবর্তনগুলো করা হয়েছে

ফাইলপরিবর্তনফলাফল
frontend/nuxt.config.tsssr: true করা হয়েছে। Static generation-এর জন্য শুধু homepage prerender করা হয়েছে।HTML parse হওয়ার সময়ই homepage content পাওয়া যাবে; LCP-এর জন্য JavaScript dependency কমবে।
frontend/app/pages/index.vueপ্রথম slider image-এর জন্য rel=preload, fetchpriority=high, width, height ও sizes যোগ করা হয়েছে।Browser hero image আগে থেকে fetch করতে পারবে এবং image layout স্থির থাকবে।
frontend/app/pages/index.vueSidebar/category thumbnail-এ loading=lazy ও decoding=async যোগ করা হয়েছে।প্রথম viewport-এর জন্য অপ্রয়োজনীয় image download কমবে।
frontend/app/components/AppFooter.vueMobile off-canvas menu-এর section image lazy-load করা হয়েছে।বন্ধ থাকা menu-এর image প্রথম page load-এ bandwidth নেবে না।

Build verification

  • npm run generate সফলভাবে সম্পন্ন হয়েছে।
  • Generated index.html-এ data-ssr="true" পাওয়া গেছে।
  • Hero image preload, fetchpriority="high", এবং width="700" height="700" যাচাই করা হয়েছে।
  • Homepage-এর hero markup generated HTML-এ উপস্থিত আছে।

Deployment note

বর্তমান পরিবর্তনগুলো লোকাল branch serverSecound-এ আছে। GitHub Actions production deployment শুধু prod branch-এ push হলে চালু হয়। তাই live ফল দেখতে এই পরিবর্তনগুলো prod-এ merge/push করতে হবে।

Frontend page কোথায় থাকে?

Development source pages থাকে frontend/app/pages-এ। Server-এর public_html-এ source folder যায় না; সেখানে Nuxt build-এর compiled index.html, 200.html এবং _nuxt files যায়। .htaccess ও 200.html দিয়ে /shop, /contact, /blog-এর মতো client-side routes কাজ করে।

পরের যাচাই

Deploy হওয়ার 5–10 মিনিট পরে PageSpeed Insights-এ homepage আবার Mobile ও Desktop mode-এ test করতে হবে। নতুন report-এ NO_LCP না থেকে একটি LCP time দেখা উচিত। Score server response time, visitor location, cache এবং test run অনুযায়ী কিছুটা ওঠানামা করতে পারে।

এই রিপোর্টটি performance fix-এর সঙ্গে তৈরি করা হয়েছে।
