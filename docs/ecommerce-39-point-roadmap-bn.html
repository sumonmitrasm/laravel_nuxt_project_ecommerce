Phase 1 — Security ও Foundation

এগুলো আগে শেষ করা উচিত; পরের feature-এর নিরাপদ ভিত্তি তৈরি করবে।

1

Public cache-clear route সরানো

Public /clear-cache route বাদ দিয়ে CLI অথবা Superadmin-only ব্যবস্থা করা।

Priority: CriticalDependency: নেই
  • Guest URL দিয়ে cache clear করতে পারে না
  • Production command documented
2

Dynamic Admin Dashboard

Today/month sales, pending/processing/shipped, customers, low stock, recent orders ও revenue chart।

Priority: HighUses: orders, users, variants
  • সব value database থেকে আসে
  • Date filter ও empty state কাজ করে
3

Low-stock Management

Threshold, low/out-of-stock list, notification এবং stock শেষ হলে cart বন্ধ।

Priority: CriticalDependency: Product variants
  • Overselling বন্ধ
  • Admin warning পায়
4

Payment Reconciliation

SSLCommerz transaction, gateway ID, callback log, amount mismatch ও duplicate callback protection।

Priority: CriticalDependency: Payment flow
  • Server validation ছাড়া Paid হয় না
  • এক callback দুইবার effect করে না
5

Automated Tests

Auth, cart merge, coupon, checkout, stock lock, payment callback, cancellation ও status transition test।

Priority: CriticalContinuous work
  • Critical feature tests pass
  • Test database isolated

Phase 2 — Order Operations

Admin যেন order সম্পূর্ণভাবে পরিচালনা করতে পারে।

6

PDF Invoice

Invoice number, seller/customer details, items, tax/discount/shipping এবং download/email।

Priority: HighDependency: Orders
  • Admin/customer download
  • Snapshot data ব্যবহার
7

Advanced Order Search

Date range, amount, phone, coupon, product/SKU ও transaction ID filter।

Priority: Medium
  • Filters combinedভাবে কাজ করে
  • Pagination query ধরে রাখে
8

Bulk Order Actions

Multiple select, bulk status, packing slip, courier export ও invoice download।

Priority: MediumDependency: 6, 7
  • Invalid transition blocked
  • Permission enforced
9

Courier Integration

Pathao/Steadfast/RedX parcel create, tracking, charge ও delivery synchronization।

Priority: MediumExternal API
  • Duplicate parcel হয় না
  • Webhook authenticated
10

Order Notes

Internal admin note ও customer-visible note আলাদা রাখা।

Priority: Medium
  • Author/time stored
  • Internal note customer দেখে না
11

Return, Replacement ও Refund

Request reason/image, approval, refund amount এবং returned stock handling।

Priority: HighDependency: 4, 6
  • Eligible delivered order only
  • Stock/payment history consistent
12

Order Activity Log

Status, address, refund ও payment পরিবর্তনে admin/user/time/history রাখা।

Priority: High
  • History immutable
  • Actor ও old/new value দেখা যায়

Phase 3 — Analytics ও Reports

সিদ্ধান্ত নেওয়ার জন্য সঠিক ও exportযোগ্য business data।

13

Custom Date Range

Today/month/year-এর পাশাপাশি From–To date report।

Priority: Medium
  • Timezone consistent
  • Invalid range validated
14

Analytics Charts

Revenue line, order bar, payment pie এবং category chart।

Priority: MediumDependency: 13
  • Filter অনুযায়ী chart বদলায়
  • Mobile responsive
15

Advanced Business Reports

Top category/brand/customer, coupon performance, cancellation rate, delivery time ও profit।

Priority: MediumProfit-এর জন্য cost_price
  • Metric definition visible
  • Cancelled/refunded handling সঠিক
16

Report Export

CSV, Excel, PDF ও print export।

Priority: MediumDependency: 13–15
  • Applied filters export-এ থাকে
  • Large export queued
17

Net Revenue Breakdown

Gross sales − coupon − refunds + shipping = net revenue আলাদাভাবে দেখানো।

Priority: High
  • Accounting formula documented
  • Dashboard/report একই ফল দেয়

Customer retention, trust এবং self-service বৃদ্ধি করবে।

Priority: Medium
  • Device/reload-এর পর থাকে
  • Duplicate item হয় না

Priority: Low

  • Mobile usable

Priority: High

Priority: Critical

23

Recently Viewed Products

Priority: Low
  • Duplicate-free ordering

Phase 7 — Admin, Security ও Operations

Production reliability, accountability ও performance।

34

Admin Audit Log

Create/update/delete/status action-এর actor, IP, old/new value ও time।

Priority: High
  • Sensitive values masked
  • Logs সাধারণ admin edit করতে পারে না
35

Admin Two-Factor Authentication

Superadmin এবং finance role-এর জন্য TOTP/recovery codes।

Priority: High
  • Recovery flow secure
  • Rate limit applied
36

Granular Permissions

Financial report, refund, export, stock, coupon ও notification-এর পৃথক access।

Priority: High
  • UI ও controller দুদিকে enforced
  • Superadmin recovery access
37

Session ও Security Hardening

Secure/HttpOnly/SameSite cookies, timeout, device history, CSP এবং production config।

Priority: Critical
  • APP_DEBUG=false in production
  • Secrets repository-তে নেই
38

Queue

Mail, notifications, image processing ও large exports background worker-এ নেওয়া।

Priority: High
  • Order mail failure-এ order fail নয়
  • Retry/failed jobs monitored
39

Scheduled Tasks

Expired coupon, flash sale, cleanup, cart reminder, daily report ও payment reconciliation।

Priority: HighDependency: Queue
  • Cron runs every minute
  • Tasks overlap করে না
