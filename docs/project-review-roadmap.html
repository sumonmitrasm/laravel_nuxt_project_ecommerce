প্রজেক্টে single-store ecommerce-এর গুরুত্বপূর্ণ ভিত্তি আছে: catalog, variant, cart, coupon, checkout, payment, inventory এবং admin workflow। বড় আকারে ব্যবহার করার আগে order/payment correctness, customer account recovery, deployment checks ও automated regression tests-এ কাজ করা সবচেয়ে জরুরি। শুধু নতুন feature বাড়ালে বর্তমান ঘাটতিগুলো দূর হবে না।

Release acceptance checklist

  • Variant order cancel, paid order cancel/refund, duplicate IPN, retry ও delayed callback-এ সঠিক status/stock।
  • দুই customer শেষ stock বা শেষ coupon slot একসঙ্গে নিতে গেলে oversell/over-redemption হবে না।
  • Guest-to-user cart merge এবং forgot/reset password journey কাজ করে।
  • Role অনুযায়ী admin access; unauthorized maintenance কাজ নিষিদ্ধ।
  • Approved desktop/mobile visual baseline, keyboard/touch flow ও direct deep links ঠিক।
  • Full frontend type-check ও backend domain tests CI-তে; config-only check-কে full coverage বলা নয়।
  • Gateway/mail/courier sandbox failure cases, staging smoke test, backup restore ও rollback পরীক্ষা।
কোনো production readiness certificate নয়: এই review-এর ভিত্তিতে “সাইট সম্পূর্ণ secure”, “সব payment flow tested” বা “নির্দিষ্ট traffic capacity নিশ্চিত” বলা যাবে না। পরের ধাপে prioritised implementation ও controlled end-to-end verification প্রয়োজন।
