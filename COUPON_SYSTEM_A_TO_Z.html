1. Architecture

Admin Form → CouponController validation → DB transaction ├─ coupons (main rules) ├─ coupon_products / categories / brands (product eligibility) └─ coupon_users (selected customer eligibility) Future Cart API → Coupon eligibility service → carts.coupon_id Future confirmed Order → coupon_usages record

একটি coupon-এর মূল নিয়ম coupons table-এ থাকে। শুধুমাত্র selected record দরকার হলে pivot table ব্যবহৃত হয়। এতে structure standard কিন্তু unnecessary rule-engine ছাড়াই সহজ থাকে।

3. Conditions কীভাবে কাজ করে

Product Eligibility — একটি নির্বাচন

ScopeEligible

categoriesনির্বাচিত category-এর products
brandsনির্বাচিত brand-এর products

Customer Eligibility — একটি নির্বাচন

Scopeনিয়ম
allসব eligible customer
selectedcoupon_users-এ থাকা customer
first_orderআগে confirmed order নেই
lifetime_spendCompleted order total ≥ minimum_lifetime_spend

Minimum Order Amount customer scope-এর বাইরে একটি independent order condition। তাই configured থাকলে product + customer + minimum cart—সব condition পূরণ করতে হবে। OR campaign দরকার হলে দুটি আলাদা coupon বানানো সহজ ও standard।

Discount calculation

// Fixed
discount = min(discount_value, eligible_subtotal)

// Percentage
discount = eligible_subtotal * discount_value / 100
discount = maximum_discount ? min(discount, maximum_discount) : discount

// Final
payable = max(0, cart_subtotal - discount)

4. Coupon Model

protected $fillable = [
    'name', 'description', 'code', 'apply_method', 'scope', 'customer_scope',
    'discount_type', 'discount_value', 'maximum_discount',
    'minimum_order_amount', 'minimum_lifetime_spend',
    'usage_limit', 'usage_limit_per_user', 'exclude_discounted_products',

];

public function products(): BelongsToMany
{
    return $this->belongsToMany(Product::class, 'coupon_products')->withTimestamps();
}

Categories, brands এবং users-এর relation একই pattern। Decimal/date/boolean fields cast করা হয়েছে, তাই controller-এ বারবার manual conversion দরকার হয় না।

'product_ids' => [Rule::requiredIf($request->scope === 'products'),'array'],

Save transaction

DB::transaction(function () use ($coupon, $data, $relations) {
    $coupon->fill($data);
    if (! $coupon->exists) $coupon->created_by_id = Auth::guard('admin')->id();
    $coupon->save();

    $coupon->products()->sync($coupon->scope === 'products' ? $relations['products'] : []);
    $coupon->categories()->sync($coupon->scope === 'categories' ? $relations['categories'] : []);
    $coupon->brands()->sync($coupon->scope === 'brands' ? $relations['brands'] : []);
    $coupon->users()->sync($coupon->customer_scope === 'selected' ? $relations['users'] : []);
});

sync([]) পুরোনো অপ্রাসঙ্গিক selection মুছে দেয়। Transaction-এর কারণে coupon save ব্যর্থ হলে pivot tables-ও partial save হয় না।

9. Cart/Checkout Apply Flow — পরবর্তী Laravel ধাপ

বর্তমান অবস্থা: Admin coupon configuration তৈরি হয়েছে। Project-এ Order module নেই, তাই first-order/lifetime/usage final enforcement এখনো complete নয়। Nonexistent order columns ধরে code লেখা হয়নি।

Recommended endpoints

GET    /api/cart/available-coupons
POST   /api/cart/coupon          { "code": "WELCOME20" }
DELETE /api/cart/coupon

Apply validation order

  1. Coupon code, active status ও schedule
  2. Cart এবং customer identity
  3. Total/per-user usage
  4. Customer scope
  5. Product scope
  6. Discounted-product exclusion
  7. Minimum eligible subtotal
  8. Discount calculation ও maximum cap
  9. Cart-এ coupon attach

Order table-এর actual status এবং total column final হওয়ার পরে উপরের names project schema অনুযায়ী বদলাতে হবে। Checkout transaction-এর মধ্যে coupon পুনরায় validate করতে হবে; শুধু cart page-এর result বিশ্বাস করা যাবে না।

10. Performance & Security

  • List pagination এবং selected columns ব্যবহার করুন।
  • Relations eager-load করে N+1 query এড়ান।
  • Coupon result নয়—small static option lists প্রয়োজন হলে cache করা যায়; invalidation ছাড়া দীর্ঘ cache নয়।
  • Frontend price/discount কখনো trusted নয়; Laravel পুনরায় calculate করবে।
  • Coupon code uppercase normalize এবং unique index রাখুন।
  • Usage count + order creation একই DB transaction-এ করুন; race condition রোধে relevant row lock করুন।
  • First-order coupon-এর জন্য login/verified phone ব্যবহার করা নিরাপদ।
  • এক cart-এ একটি coupon; নতুনটি apply করলে আগেরটি replace হবে।
