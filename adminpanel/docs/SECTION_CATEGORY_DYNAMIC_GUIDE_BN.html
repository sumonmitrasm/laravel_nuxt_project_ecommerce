১. মূল ধারণা

Admin panel থেকে Section ও Category save হয়, Laravel API সেগুলো JSON বানায়, Nuxt সেই JSON এনে বিভিন্ন design-এর মধ্যে দেখায়।

২. Database-এ Section ও Category কীভাবে linked?

sections
├── id
├── name
├── image
└── status

categories
├── id
├── section_id  ─────► sections.id
├── parent_id   ─────► categories.id
├── category_name
├── image
└── url

section_id বলে Category কোন Section-এর। parent_id = 0 হলে root Category; অন্য Category id হলে Subcategory।

উদাহরণ: Electronics-এর id 1 এবং Laptops-এর section_id 1—তাই Laptops Electronics-এর অধীনে।

৪. Section Model-এর কাজ

protected $fillable = ['name', 'image', 'status'];
protected $appends = ['image_url'];

$fillable database save অনুমোদন করে। $appends API response-এ computed image_url যোগ করে।

public function getImageUrlAttribute(): ?string
{
    return $this->image
        ? asset('admin/sectionimage/'.basename($this->image))
        : null;
}
Frontend-এ section.image_url ব্যবহার করবেন; section.image শুধু filename।

Relationship

public function categories(): HasMany
{
    return $this->hasMany(Category::class)
        ->where('parent_id', 0)
        ->where('status', true)
        ->with(['subcategories', 'products.brand']);
}

৫. Laravel API কীভাবে তৈরি?

Route::get('/menu', [FrontController::class, 'menu']);
public function menu(): JsonResponse
{
    $sections = Cache::remember(
        'api.sections-with-categories.v4',
        now()->addHours(6),
        fn () => Section::sections()
    );

    return response()->json([
        'status' => true,
        'categories' => $sections,
    ]);
}

Response shape

{
  "status": true,
  "categories": [
    {
      "id": 1,
      "name": "Electronics",
      "image_url": "http://.../electronics.webp",
      "categories": [
        {
          "category_name": "Laptops",
          "url": "laptops",
          "subcategories": []
        }
      ]
    }
  ]
}

data.categories হচ্ছে Section array; প্রতিটি Section-এর section.categories হচ্ছে Category array।

৬. Nuxt কীভাবে Laravel-এর সঙ্গে connected?

frontend/nuxt.config.ts

runtimeConfig: {
  public: {
    apiBase: 'http://127.0.0.1:8000/api'
  }
}

এর সঙ্গে /menu যোগ হয়ে full URL হয়:

http://127.0.0.1:8000/api + /menu = http://127.0.0.1:8000/api/menu
nuxt.config পরিবর্তনের পরে npm run dev restart করতে হবে।

৭. Shared composable কেন?

Header, Home এবং Mobile menu—সব জায়গায় একই API দরকার। Fetch code copy না করে এক জায়গায় রাখা হয়েছে।

frontend/app/composables/useCatalogMenu.ts

export const useCatalogMenu = () => {
  const config = useRuntimeConfig()

  return useFetch('/menu', {
    baseURL: config.public.apiBase,
    key: 'catalog-menu'
  })
}

ব্যবহার:

const { data, pending, error } = await useCatalogMenu()

const sections = computed(() =>
  data.value?.categories ?? []
)

?? [] data আসার আগেও empty array দেয়—তাই template crash করে না।

৮. Hero sidebar dynamic করা

<div
  v-for="section in sections"
  :key="section.id"
  class="desktop-category-item"
>
  <img
    v-if="section.image_url"
    :src="section.image_url"
    :alt="section.name"
  >
  {{ section.name }}
</div>
Vue codeকাজ
v-forArray-এর সব Section দেখায়
:keyপ্রতিটি item-এর unique identity
v-ifImage থাকলেই image দেখায়
:srcAPI value HTML attribute-এ bind করে
.sidebar-section-image {
  width: 22px;
  height: 22px;
  object-fit: contain;
}

sectionIcons API connection নয়; image না থাকলে fallback icon দেখানোর optional ব্যবস্থা।

৯. Section → Category → Subcategory nested menu

Section loop └── Category loop └── Subcategory loop
<div v-for="section in sections" :key="section.id">
  <div
    v-for="category in section.categories"
    :key="category.id"
  >
    <NuxtLink
      v-for="sub in category.subcategories"
      :key="sub.id"
      :to="{ path: '/shop', query: { category: sub.url } }"
    >
      {{ sub.category_name }}
    </NuxtLink>
  </div>
</div>

১০. Section tab click করলে Category বদলায় কীভাবে?

const activeSectionId = ref(sections.value[0]?.id ?? null)

const activeSection = computed(() =>
  sections.value.find(
    section => section.id === activeSectionId.value
  ) ?? sections.value[0] ?? null
)
<button
  v-for="section in sections"
  @click="activeSectionId = section.id"
>
  {{ section.name }}
</button>

<div v-for="category in activeSection.categories">
  {{ category.category_name }}
</div>

১৪. Category listing ও product details

GET /api/menu ↓ Category click /shop?category=laptops ↓ GET /api/listing/laptops ↓ Product click /product/15 ↓ GET /api/detail/15

বর্তমানে menu link query তৈরি করে। Shop page-এ query পড়ে /listing/{url} fetch করলে products dynamic হবে।

১৫. Cache কেন clear করতে হয়?

Menu API ৬ ঘণ্টা cache হয়। Admin update-এর পরে cache clear না হলে পুরোনো data দেখা যেতে পারে।

Cache::forget('api.sections-with-categories.v4');
php artisan optimize:clear

Browser hard refresh: Ctrl + F5

১৭. Common errors

404 Not Found

Laravel-এ `/categories` route না থাকলে useFetch('/categories') কাজ করবে না। Existing route অনুযায়ী useFetch('/menu') দিতে হবে।

API Error: undefined

এটি error নয়; error.value empty মানে request সফল।

Image দেখা যায় না

// ভুল
section.image

// সঠিক
section.image_url

Reload দিলে কাজ করে

Plain DOM listener-এর বদলে Vue ref, computed ও @click ব্যবহার করুন।

১৮. অন্য project-এ করার checklist

  1. Section ও Category tables বানান।
  2. categories.section_id link করুন।
  3. Model relationships লিখুন।
  4. Section image-এর full image_url দিন।
  5. /api/menu endpoint বানান।
  6. Nuxt API base URL configure করুন।
  7. Shared composable বানান।
  8. Section ও nested Category-তে v-for দিন।
  9. Category URL দিয়ে dynamic NuxtLink বানান।
  10. Loading/error/empty state রাখুন।
  11. Images fixed size ও object-fit দিন।
  12. Mobile collapse id unique করুন।
  13. Cache invalidation করুন।
  14. Desktop/mobile এবং production build পরীক্ষা করুন।
Core rule: API একবার shared composable দিয়ে fetch করুন; একই JSON আলাদা Vue template/design-এ render করুন।
