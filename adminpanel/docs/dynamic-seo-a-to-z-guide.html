1. মূল ধারণা

Laravel Blade project-এ controller থেকে variables পাঠিয়ে layout-এ meta tag বসাতেন। Nuxt project-এ Laravel HTML render করছে না; Laravel JSON API দেয় এবং Nuxt সেই JSON নিয়ে server-side HTML head তৈরি করে।

Database — settings/product/category SEO fields
↓
Laravel PageSeo — fallback resolve করে একই shape বানায়
↓
FrontController API — response-এর seo key-তে পাঠায়
↓
Nuxt page — API response নেয়
↓
usePageSeo — title, meta, OG, Twitter, canonical ও JSON-LD head-এ বসায়
মূল নিয়ম: Page-specific value না থাকলে settings-এর default value ব্যবহার হবে। তাই প্রত্যেক record-এ সব SEO field পূরণ করা বাধ্যতামূলক নয়।

2. Request এলে কোনটি আগে চলে?

  1. User Nuxt-এর /product?id=1 খোলে।
  2. frontend/app/pages/product.vue Laravel-এর /api/detail/1 endpoint call করে।
  3. adminpanel/routes/api.php request-টি FrontController::details()-এ পাঠায়।
  4. Controller product load করে এবং $this->seo->product($product) call করে।
  5. PageSeo title/description/image-এর fallback ঠিক করে array ফেরত দেয়।
  6. Laravel JSON-এ product এবং seo ফেরত দেয়।
  7. Nuxt-এর pageSeo computed সেই seo data ধরে।
  8. usePageSeo(pageSeo) SSR-এর সময় HTML <head> তৈরি করে।
  9. Google/Facebook crawler ready meta tags পায়।

4. Laravel-এর কেন্দ্রীয় PageSeo class

File: adminpanel/app/Support/PageSeo.php

<?php

namespace App\Support;

use App\Models\Category;
use App\Models\Product;
use App\Models\Setting;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Str;

class PageSeo
{
    public function home(): array
    {
        return $this->build();
    }

    public function shop(): array
    {
        return $this->build(canonical: $this->frontendUrl('/shop'));
    }

    public function category(Category $category): array
    {
        return $this->build(
            title: $category->meta_title ?: $category->category_name,
            description: $category->meta_description ?: $category->description,
            keywords: $category->meta_keywords,
            robots: $category->meta_robot,
            canonical: $this->frontendUrl('/shop?category='.
                rawurlencode((string) $category->url)),
            image: $category->image_url,
            schema: $category->schema_markup,
        );
    }

    public function product(Product $product): array
    {
        $productUrl = $this->frontendUrl('/product?id='.$product->id);

        return $this->build(
            title: $product->meta_title ?: $product->product_name,
            description: $product->meta_description ?: $product->description,
            keywords: $product->meta_keywords,
            robots: $product->meta_robot,
            canonical: $this->canonicalUrl($product->canonical_tag, $productUrl),
            image: $this->productImage($product),
            schema: $product->schema_markup,
            type: 'product',
        );
    }

    private function build(
        ?string $title = null,
        ?string $description = null,
        ?string $keywords = null,
        ?string $robots = null,
        ?string $canonical = null,
        ?string $image = null,
        ?string $schema = null,
        string $type = 'website',
    ): array {
        $setting = $this->setting();
        $siteName = trim((string) (($setting['side_name'] ?? null) ?: 'NovaCart'));
        $resolvedTitle = trim((string) ($title ?: ($setting['meta_title'] ?? null) ?: $siteName));

        if ($title && $siteName &&
            ! Str::contains(Str::lower($resolvedTitle), Str::lower($siteName))) {
            $resolvedTitle .= ' | '.$siteName;
        }

        return [
            'title' => $resolvedTitle,
            'description' => $this->plainText(
                $description ?: ($setting['meta_description'] ?? null)
                ?: ($setting['description'] ?? null)
            ),
            'keywords' => $keywords ?: ($setting['meta_keywords'] ?? null),
            'robots' => $this->robots($robots)
                ?: $this->robots($setting['meta_robot'] ?? null)
                ?: 'index, follow',
            'canonical' => $this->canonicalUrl(
                $canonical ?: ($setting['canonical_tag'] ?? null),
                $this->frontendUrl(),
            ),
            'image' => $image ?: $this->settingImage($setting),
            'type' => $type,
            'schema' => $schema ?: ($setting['schema_markup'] ?? null),
        ];
    }

    private function setting(): ?array
    {
        return Cache::remember(
            'api.general-setting.seo.v1',
            now()->addHours(6),
            fn () => Setting::query()->where('status', true)
                ->latest('id')->first()?->toArray(),
        );
    }

    private function frontendUrl(string $path = ''): string
    {
        return rtrim((string) config(
            'app.frontend_url', 'http://localhost:3000'
        ), '/').$path;
    }

    private function canonicalUrl(?string $candidate, string $fallback): string
    {
        if (! $candidate || ! filter_var($candidate, FILTER_VALIDATE_URL)) {
            return $fallback;
        }

        $frontendHost = parse_url($this->frontendUrl(), PHP_URL_HOST);
        $candidateHost = parse_url($candidate, PHP_URL_HOST);

        return $frontendHost && $candidateHost === $frontendHost
            ? $candidate : $fallback;
    }

    private function robots(?string $value): ?string
    {
        if (! $value) return null;

        $normalized = Str::of($value)->lower()
            ->replaceMatches('/\s+/', ' ')->trim()->toString();

        return preg_match('/^(index|noindex)\s*,\s*(follow|nofollow)$/', $normalized)
            ? preg_replace('/\s*,\s*/', ', ', $normalized)
            : null;
    }

    private function settingImage(?array $setting): ?string
    {
        $filename = ($setting['meta_image'] ?? null) ?: ($setting['image'] ?? null);
        return $filename
            ? asset('admin/site_settings/'.basename($filename))
            : null;
    }

    private function productImage(Product $product): ?string
    {
        if ($product->meta_image) {
            return asset('admin/productimage/'.basename($product->meta_image));
        }

        return $product->image_url;
    }

    private function plainText(?string $value): ?string
    {
        if (! $value) return null;
        return Str::of($value)->stripTags()->squish()->limit(200)->toString();
    }
}

কেন একটি central class?

প্রতিটি controller-এ একই fallback code লিখতে হয় না। ভবিষ্যতে rules বদলালে শুধু এই class বদলালেই সব page update হবে। Laravel service container constructor-এর PageSeo নিজে inject করতে পারে; আলাদা registration প্রয়োজন নেই।

6. Nuxt-এর reusable composable

File: frontend/app/composables/usePageSeo.ts

import type { Ref } from 'vue'

export type PageSeoData = {
  title: string
  description: string | null
  keywords: string | null
  robots: string
  canonical: string | null
  image: string | null
  type: 'website' | 'product'
  schema: string | Record<string, unknown> | null
}

export const usePageSeo = (
  seo: Ref<PageSeoData | null | undefined>
) => {
  const schema = computed<Record<string, unknown> | null>(() => {
    const value = seo.value?.schema

    if (!value) return null
    if (typeof value !== 'string') return value

    try {
      const parsed = JSON.parse(value)
      return parsed && typeof parsed === 'object' && !Array.isArray(parsed)
        ? parsed
        : null
    } catch {
      return null
    }
  })

  useSeoMeta({
    title: () => seo.value?.title || 'NovaCart',
    description: () => seo.value?.description || undefined,
    robots: () => seo.value?.robots || 'index, follow',
    ogTitle: () => seo.value?.title || 'NovaCart',
    ogDescription: () => seo.value?.description || undefined,
    ogUrl: () => seo.value?.canonical || undefined,
    ogImage: () => seo.value?.image || undefined,
    ogType: 'website',
    twitterCard: 'summary_large_image',
    twitterTitle: () => seo.value?.title || 'NovaCart',
    twitterDescription: () => seo.value?.description || undefined,
    twitterImage: () => seo.value?.image || undefined,
  })

  useHead(() => ({
    meta: seo.value?.keywords
      ? [{ name: 'keywords', content: seo.value.keywords }]
      : [],
    link: seo.value?.canonical
      ? [{ rel: 'canonical', href: seo.value.canonical }]
      : [],
    script: schema.value
      ? [{
          key: 'page-schema',
          type: 'application/ld+json',
          textContent: JSON.stringify(schema.value)
            .replaceAll('<', '\\u003C'),
        }]
      : [],
  }))
}

প্রতিটি অংশের কাজ

  • PageSeoData: Laravel response-এর TypeScript contract। ভুল field name ধরতে সাহায্য করে।
  • computed: API data পরে এলেও head reactiveভাবে update হয়।
  • useSeoMeta: title, description, robots, Open Graph ও Twitter tags তৈরি করে।
  • useHead: keywords, canonical link এবং JSON-LD script তৈরি করে।
  • replaceAll('<', '\\u003C'): schema JSON-এর মধ্যে malicious closing script injection-এর ঝুঁকি কমায়।
ogType এখানে website রাখা হয়েছে Unhead TypeScript compatibility-এর জন্য। Product-এর অর্থপূর্ণ structured data Product JSON-LD schema দিয়ে প্রকাশ করবেন।

9. যেকোনো নতুন dynamic page যোগ করার recipe

  1. Model/table-এ প্রয়োজনীয় SEO fields রাখুন। সব field nullable হতে পারে।
  2. PageSeo-তে ওই entity-এর public method যোগ করুন।
  3. Controller API response-এর seo key-তে method result দিন।
  4. Nuxt response type-এ seo: PageSeoData যোগ করুন।
  5. computed(() => data.value?.seo) তৈরি করুন।
  6. usePageSeo(pageSeo) call করুন।
  7. View Source ও social debugger দিয়ে পরীক্ষা করুন।

10. Tag page-এর complete example

Tag-এর আলাদা meta image না রাখতে চাইলে tag page-এর প্রথম product image অথবা settings image fallback করা যায়। তবে listing order বদলালে social image বদলে যেতে পারে; stable branding চাইলে settings image নেওয়া ভালো।

// PageSeo.php
use App\Models\Tag;

public function tag(Tag $tag): array
{
    return $this->build(
        title: $tag->meta_title ?: $tag->name,
        description: $tag->meta_description ?: $tag->description,
        keywords: $tag->meta_keywords,
        robots: $tag->meta_robot,
        canonical: $this->frontendUrl('/tag/'.$tag->slug),
        // image না পাঠালে build() settings image নেবে
        schema: $tag->schema_markup,
    );
}
// FrontController.php
public function tag(string $slug): JsonResponse
{
    $tag = Tag::where('slug', $slug)->where('status', true)->firstOrFail();
    $products = $tag->products()->where('status', true)->paginate(20);

    return response()->json([
        'status' => true,
        'tag' => $tag,
        'products' => $products,
        'seo' => $this->seo->tag($tag),
    ]);
}
// routes/api.php
Route::get('/tag/{slug}', [FrontController::class, 'tag']);
// frontend/app/pages/tag/[slug].vue
const route = useRoute()
const config = useRuntimeConfig()
const { data } = await useFetch(`/tag/${route.params.slug}`, {
  baseURL: config.public.apiBase,
})
usePageSeo(computed(() => data.value?.seo))

13. Common mistakes ও best practice

  • Meta image-এ relative path নয়, absolute public URL দিন।
  • Canonical হিসেবে admin/API domain নয়, frontend page URL দিন।
  • এক page-এ একটিই canonical রাখুন।
  • Database থেকে সরাসরি arbitrary canonical domain বিশ্বাস করবেন না—বর্তমান helper frontend host validate করে।
  • Description-এর HTML strip করুন এবং reasonable length রাখুন—বর্তমান helper 200 character limit করে।
  • Schema field-এ valid JSON রাখুন; invalid JSON হলে composable সেটি বাদ দেয়।
  • Product/category main image থাকলে অকারণে duplicate meta image upload করবেন না।
  • Settings update করার পরে 6-hour cache থাকায় সঙ্গে সঙ্গে পুরনো SEO আসতে পারে। Cache forget/clear বা versioned key update করুন।
  • /clear-cache-এর মতো public GET route production-এ নিরাপদ নয়; admin-auth/permission ও POST action ব্যবহার করা উচিত।
  • Google ranking-এর জন্য meta keywords-এর গুরুত্ব খুব কম; title, description, content, canonical, performance ও structured data বেশি গুরুত্বপূর্ণ।
