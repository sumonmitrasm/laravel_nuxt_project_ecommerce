Shipping Method System — সম্পূর্ণ বাংলা গাইড

Admin CRUD থেকে checkout radio selection এবং total পর্যন্ত shipping method-এর সম্পূর্ণ implementation এখানে ব্যাখ্যা করা হয়েছে।

১. সম্পূর্ণ flow

Admin shipping method তৈরি/সম্পাদনা করে → Laravel database-এ save → API cache clear → public API শুধু active methods দেয় → Nuxt composable list রাখে → checkout radio-তে method ID bind হয় → selected ID দিয়ে সম্পূর্ণ method find হয় → charge subtotal-এর সঙ্গে যোগ হয়।

Fieldঅর্থ

minimum_days ও maximum_days রাখা হয়নি। বর্তমান design-এ admin-friendly delivery_time text যথেষ্ট। ভবিষ্যতে delivery date calculation দরকার হলে তখন numeric day fields যুক্ত করবেন।

৬. Public API

GET /api/shipping-methods
$methods = Cache::remember('api.shipping-methods.v1', now()->addHours(6), fn () =>
    ShippingMethod::query()->where('status', true)
      ->orderBy('position')->orderBy('id')
      ->get(['id','name','code','description','charge','delivery_time','icon'])
      ->toArray()
);

এটি public read-only endpoint। Admin create/update/status/delete হলে Cache::forget('api.shipping-methods.v1') হয়, ফলে checkout পরের request-এই নতুন data পায়; ৬ ঘণ্টা অপেক্ষা করতে হয় না।

৭. Nuxt composable

export type ShippingMethod = {
  id: number
  name: string
  code: string
  description: string | null
  charge: string
  delivery_time: string | null
  icon: string | null
}

const shippingMethods = useState<ShippingMethod[]>('shipping-methods', () => [])

const fetchShippingMethods = async () => {
  const response = await $fetch('/shipping-methods', {
    baseURL: config.public.apiBase
  })
  shippingMethods.value = response.shipping_methods
}

baseURL যদি http://localhost:8000/api হয়, final link হয় http://localhost:8000/api/shipping-methods।

৮. Checkout ID selection

const selectedShippingMethodId = ref<number | null>(null)

const selectedShippingMethod = computed(() =>
  shippingMethods.value.find(
    method => method.id === selectedShippingMethodId.value
  ) ?? null
)
<label v-for="method in shippingMethods" :key="method.id">
  <input
    v-model="selectedShippingMethodId"
    type="radio"
    name="checkoutShipping"
    :value="method.id"
  >
  {{ method.name }}
</label>

User radio select করলে selectedShippingMethodId-তে method-এর numeric ID যায়। find() সেই ID match করে full object বের করে। :key Vue list rendering-এর জন্য, আর :value selected ID-এর জন্য।

৯. Charge এবং total

const shippingCharge = computed(() =>
  Number(selectedShippingMethod.value?.charge ?? 0)
)

const checkoutSubtotal = computed(() =>
  Number(cart.value?.summary.subtotal ?? 0)
)

const checkoutTotal = computed(() =>
  checkoutSubtotal.value + shippingCharge.value
)

Laravel decimal সাধারণত JSON-এ string হতে পারে, তাই Number() দিয়ে arithmetic-এর আগে number করা হয়েছে। Method বদলালে computed values automatic update হয়।

১০. প্রথম method default select

await fetchShippingMethods()
const firstShippingMethod = shippingMethods.value[0]
if (!selectedShippingMethodId.value && firstShippingMethod) {
  selectedShippingMethodId.value = firstShippingMethod.id
}

API position অনুযায়ী sort করে, তাই সবচেয়ে কম position-এর active method শুরুতে select হয়। Array খালি হতে পারে বলে আগে firstShippingMethod check করা হয়েছে।

১১. Order submit-এর সময় অবশ্যই যা করবেন

বর্তমান UI selection/summary dynamic। Order API তৈরি করার সময় frontend থেকে শুধু shipping_method_id পাঠাবেন। Backend আবার active method database থেকে load করে charge নেবে। Frontend পাঠানো charge কখনও বিশ্বাস করবেন না—user DevTools দিয়ে তা বদলাতে পারে।
// frontend request
{ shipping_method_id: selectedShippingMethodId.value }

// backend principle
$method = ShippingMethod::where('status', true)
    ->findOrFail($request->integer('shipping_method_id'));
$shippingCharge = $method->charge;
$total = $subtotal + $shippingCharge;
