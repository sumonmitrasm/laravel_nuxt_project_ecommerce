Delivery Address System — সম্পূর্ণ বাংলা গাইড

এই document-এ database, Laravel model/controller/API, Nuxt composable, checkout এবং account page—সব file link, ID এবং data flow আলাদা করে দেখানো হয়েছে। Project root ধরে path দেওয়া হয়েছে।

১. সম্পূর্ণ flow

Page load → divisions API → Division select → selected division ID দিয়ে districts API → District select → selected district ID দিয়ে upazilas API → form submit → তিনটি numeric ID validation → user_addresses table-এ save → API response-এ ID-এর সঙ্গে readable name → checkout/account card-এ display।

৩. Database ID design

$table->foreignId('user_id')->constrained()->cascadeOnDelete();
$table->integer('division');
$table->integer('district');
$table->integer('upazila');
$table->boolean('is_default')->default(false);
$table->softDeletes();

division=4 অর্থ divisions table-এর id=4 record। একইভাবে district/upazila-তেও ID save হয়। Khulna text integer column-এ পাঠালে “Incorrect integer value” error হবে।

আরও শক্ত database integrity চাইলে existing data পরিষ্কার করে future migration-এ columns-কে foreignId(...)->constrained(...) করা যায়। বর্তমান code application validation দিয়ে সম্পর্ক যাচাই করে।

এই relationship-এর কারণে $division->districts() শুধুমাত্র ঐ division-এর district এবং $district->upazilas() শুধুমাত্র ঐ district-এর upazila দেয়।

৫. Location API route ও URL

GET /api/locations/divisions
GET /api/locations/divisions/{division}/districts
GET /api/locations/districts/{district}/upazilas

উদাহরণ: division ID 4 select হলে URL হবে /api/locations/divisions/4/districts। Laravel route model binding-এর মাধ্যমে {division}=4 থেকে Division $division model খুঁজে দেয়। District ID 35 হলে upazila URL হয় /api/locations/districts/35/upazilas। whereNumber() text parameter আটকায়।

public function districts(Division $division): JsonResponse
{
    $districts = $division->districts()
        ->orderBy('name')->get(['id','name','bn_name'])->toArray();
    return response()->json(['status' => true, 'locations' => $districts]);
}

৬. Nuxt cascading dropdown

const selectedDivisionId = ref<number | null>(null)
const selectedDistrictId = ref<number | null>(null)
const selectedUpazilaId = ref<number | null>(null)

const onDivisionChange = async () => {
  selectedDistrictId.value = null
  selectedUpazilaId.value = null
  districts.value = selectedDivisionId.value
    ? await fetchDistricts(selectedDivisionId.value) : []
  upazilas.value = []
}

const onDistrictChange = async () => {
  selectedUpazilaId.value = null
  upazilas.value = selectedDistrictId.value
    ? await fetchUpazilas(selectedDistrictId.value) : []
}
<select v-model="selectedDivisionId" @change="onDivisionChange">
  <option v-for="division in divisions" :key="division.id" :value="division.id">
    {{ division.name }}
  </option>
</select>

:value="division.id" সবচেয়ে গুরুত্বপূর্ণ: screen-এ name দেখা যায়, কিন্তু variable-এ numeric ID থাকে। :key Vue rendering identity; এটি database-এ যায় না।

Laravel প্রথমে IDs সংশ্লিষ্ট table-এ আছে কি না দেখে। এরপর district-এর division_id submitted division-এর সমান এবং upazila-এর district_id submitted district-এর সমান কি না দেখে। তাই DevTools দিয়ে ভুল ID পাঠালেও 422 validation error হবে।

৯. ID save হলেও name কীভাবে আসে

public function locationDivision(): BelongsTo
{
    return $this->belongsTo(Division::class, 'division');
}

public function getDivisionNameAttribute(): ?string
{
    return $this->locationDivision?->name;
}

$appends-এ division_name, district_name, upazila_name থাকায় JSON-এ numeric IDs এবং readable names—দুটিই আসে। UI তাই address.division_name দেখাতে পারে।

১০. CSRF ও CRUD composable

GET-এ CSRF প্রয়োজন নেই। POST/PATCH/DELETE-এর আগে /sanctum/csrf-cookie call করে X-XSRF-TOKEN header পাঠানো হয়। credentials:'include' Laravel session cookie পাঠায়। Mutation সফল হলে fetchAddresses(true) নতুন list reload করে।

১২. গুরুত্বপূর্ণ rules

  • Database integer field-এ location name পাঠাবেন না।
  • Frontend validation-কে security মনে করবেন না; backend relation validation অবশ্যই থাকবে।
  • Address update/delete সবসময় authenticated user relation দিয়ে করবেন।
  • এক user-এর একটিই default রাখতে transaction ব্যবহার করুন।
  • Location cache-এ Eloquent object নয়, toArray() result রাখা হয়েছে।
