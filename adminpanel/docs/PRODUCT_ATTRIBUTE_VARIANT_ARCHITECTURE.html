Product Attribute, Variant ও Category Filter System

১. মূল ধারণা

Attribute হলো option-এর নাম—যেমন Size, Color, RAM। Attribute Value হলো তার possible value—যেমন L, Black, 16GB। Variant হলো বিক্রয়যোগ্য নির্দিষ্ট combination—যেমন Black + XL, যার নিজস্ব SKU, price ও stock থাকে।

বিষয়উদাহরণকোথায় থাকে
AttributeSizeattributes
Attribute valueXLattribute_values
Category mappingClothing → Sizecategory_attribute
VariantBlack + XL; SKU TSH-BLK-XLproduct_variants
Variant/value mappingVariant 10 → Black, XLattribute_value_product_variant
ভুল pattern: Size attribute-এর ভেতর 8GB রাখা যাবে না; 8GB হবে RAM attribute-এর value। “6”, “8” বা ব্যক্তির নাম attribute নয়।
Color single source: পুরোনো colors table এবং products.product_color column remove করা হয়েছে। এখন Color শুধুমাত্র attributes (slug=color) ও attribute_values.color_code থেকে manage হয়। Existing product colors cleanup migration দিয়ে variants-এ migrate হয়েছে।

৩. Database tables ও migrations

৩.১ attributes

Schema::create('attributes', function (Blueprint $table) {
    $table->id();
    $table->string('name');                 // Size, Color, RAM
    $table->string('slug')->unique();       // size, color, ram
    $table->enum('type', ['text','color'])->default('text');
    $table->unsignedInteger('position')->default(0);
    $table->boolean('status')->default(true);
    $table->timestamps();
});

৩.২ attribute_values

Schema::create('attribute_values', function (Blueprint $table) {
    $table->id();
    $table->foreignId('attribute_id')->constrained('attributes')->cascadeOnDelete();
    $table->string('value');                // XL, Black, 16GB
    $table->string('color_code', 20)->nullable();
    $table->unsignedInteger('position')->default(0);
    $table->boolean('status')->default(true);
    $table->timestamps();
    $table->unique(['attribute_id', 'value']);
});

৩.৩ category_attribute

Schema::create('category_attribute', function (Blueprint $table) {
    $table->foreignId('category_id')->constrained('categories')->cascadeOnDelete();
    $table->foreignId('attribute_id')->constrained('attributes')->cascadeOnDelete();
    $table->boolean('is_filterable')->default(true);
    $table->boolean('is_required')->default(false);
    $table->unsignedInteger('position')->default(0);
    $table->primary(['category_id', 'attribute_id']);
    $table->index(['category_id', 'is_filterable']);
});
Pivot fieldকাজ
is_filterableNuxt shop sidebar-এ attribute দেখাবে কি না।
is_requiredAdmin product variant-এর প্রতিটি row-তে value বাধ্যতামূলক কি না।
positionProduct form/filter-এ display order।

৩.৪ product_variants

Schema::create('product_variants', function (Blueprint $table) {
    $table->id();
    $table->foreignId('product_id')->constrained('products')->cascadeOnDelete();
    $table->string('sku')->unique();
    $table->decimal('price', 12, 2)->nullable(); // null হলে product price
    $table->unsignedInteger('stock')->default(0);
    $table->boolean('status')->default(true);
    $table->timestamps();
    $table->index(['product_id', 'status']);
});

৩.৫ attribute_value_product_variant

Schema::create('attribute_value_product_variant', function (Blueprint $table) {
    $table->foreignId('product_variant_id')->constrained('product_variants')->cascadeOnDelete();
    $table->foreignId('attribute_value_id')->constrained('attribute_values')->cascadeOnDelete();
    $table->primary(['product_variant_id','attribute_value_id'], 'variant_attribute_value_primary');
});
সব foreign key-তে cascade থাকার কারণে Product delete হলে variants/pivot, Attribute delete হলে values/pivot এবং Category delete হলে mapping পরিষ্কার হয়। Used Attribute/Value admin controller থেকে delete করার আগে আলাদাভাবে আটকানো হয়েছে।

৪. Eloquent models ও relationships

ProductAttributeDefinition

class ProductAttributeDefinition extends Model
{
    protected $table = 'attributes';
    protected $fillable = ['name','slug','type','position','status'];
    public function values(): HasMany {
        return $this->hasMany(ProductAttributeValue::class, 'attribute_id');
    }
    public function categories(): BelongsToMany {
        return $this->belongsToMany(Category::class, 'category_attribute', 'attribute_id', 'category_id')
            ->withPivot(['is_filterable','is_required','position']);
    }
}

৬. Category → Attribute mapping

Category create/edit form-এর Product Attributes table-এ Use, Shop Filter, Required ও Order দেওয়া হয়। Save-এর সময় শুধুমাত্র Use checked rows sync হয়।

private function syncAttributes(Request $request, Category $category): void
{
    $availableIds = ProductAttributeDefinition::where('status', true)->pluck('id');
    $sync = collect($request->input('category_attributes', []))
        ->filter(fn ($row, $id) => !empty($row['enabled']) && $availableIds->contains((int)$id))
        ->mapWithKeys(fn ($row, $id) => [(int)$id => [
            'is_filterable' => (bool)($row['is_filterable'] ?? false),
            'is_required'   => (bool)($row['is_required'] ?? false),
            'position'      => (int)($row['position'] ?? 0),
        ]]);
    $category->attributes()->sync($sync->all());
}

Inheritance rule

Selected category-তে mapping থাকলে সেটি ব্যবহার হয়। mapping না থাকলে parent category-এর দিকে যাওয়া হয়। প্রথম mapping পাওয়া গেলে সেটিই applicable mapping। ফলে Clothing-এর child category নিজস্ব mapping না দিলে Clothing-এর Size/Color inherit করতে পারে।

UI dependency: Use off করলে Shop Filter এবং Required off/disabled হয়। আগে reload-এর পর Shop Filter checked দেখানোর display bug এই dependency reset দিয়ে ঠিক করা হয়েছে।

৭. Product create/edit variants

ProductController index active Attribute + Values এবং category-wise resolved mapping view-তে পাঠায়। JavaScript selected category অনুযায়ী groups filter করে।

const variantAttributeGroups = /* Laravel Js::from($variantAttributes) */;
const categoryAttributeMap   = /* Laravel Js::from($categoryAttributeMap) */;

function applicableVariantAttributeGroups() {
    const categoryId = document.querySelector('[name="category_id"]')?.value;
    const mapping = categoryAttributeMap[String(categoryId)] || {};
    return variantAttributeGroups
        .filter(a => Object.hasOwn(mapping, String(a.id)))
        .sort((a,b) => (mapping[a.id]?.position || 0) - (mapping[b.id]?.position || 0));
}

প্রতি Variant row-তে applicable attribute dropdowns + Price + Stock + SKU থাকে। Required mapping হলে select field-এ HTML required এবং server validation দুটোই কাজ করে। Blank variant price হলে মূল product price ব্যবহার করার নিয়ম রাখা হয়েছে। Blank SKU দিলে backend product code + random suffix দিয়ে SKU বানায়।

Central pricing rule

variant.price null হলে Base Price, নইলে Variant Price regular price হয়। Product discount 0-এর বেশি হলে সেটি Category discount-কে override করে; অন্যথায় Category discount fallback হয়। একই percentage effective regular price-এর ওপর প্রয়োগ হয়। Backend regular_price, effective_discount ও final_price API-তে পাঠায়।

$regularPrice = $variant->price ?? $product->product_price;
$discount = $product->product_discount > 0
    ? $product->product_discount
    : $product->category->category_discount;
$finalPrice = $regularPrice - ($regularPrice * $discount / 100);

Save algorithm

$product->variants()->delete();
foreach ($validRows as $row) {
    $variant = $product->variants()->create([
        'sku'    => $row['sku'] ?: $product->product_code.'-'.str()->upper(str()->random(6)),
        'price'  => $row['price'] !== '' ? $row['price'] : null,
        'stock'  => $row['stock'] !== '' ? $row['stock'] : 0,
        'status' => (bool)($row['status'] ?? true),
    ]);
    $variant->values()->sync(collect($row['values'])->filter()->unique()->values());
}

Update transaction-এর মধ্যে পুরোনো variant rows replace হয়। Unique SKU database index race condition থেকেও duplicate আটকায়।

৮. Server-side validation

  • সর্বোচ্চ 100 variant rows।
  • Price numeric এবং non-negative।
  • Stock integer এবং non-negative।
  • Selected value active attribute_values row হতে হবে।
  • Value যে Attribute dropdown থেকে এসেছে, database-এ সেই attribute-এরই value হতে হবে।
  • Selected Category-তে Attribute applicable হতে হবে।
  • Required Attribute প্রতিটি non-empty variant-এ থাকতে হবে।
  • এক Product-এর duplicate option combination নিষিদ্ধ।
  • Request-এর ভেতর এবং অন্য Product-এর সঙ্গে duplicate SKU নিষিদ্ধ।
// Concept: Size=XL + Color=Black combination দুইবার দেওয়া যাবে না
$combination = $selectedValueIds->sort()->implode('-');
if (isset($combinations[$combination])) {

৯. AJAX navigation ও reload-independent JavaScript

Admin layout-এর loadAjaxPage() complete response থেকে শুধু #ajax-page-content replace করে। প্রথম implementation-এ $.parseHTML() scripts বাদ দেওয়ায় Add Variant/Image handlers reload ছাড়া চলত না। সমাধান:

var $response = $('<div>').append($.parseHTML(html, document, true));
var $newContent = $response.find('#ajax-page-content').first();
var scripts = $newContent.find('script').map(function () {
    return this.textContent || this.innerText || '';
}).get();
$newContent.find('script').remove();
$content.html($newContent.html());
scripts.forEach(script => { if (script.trim()) $.globalEval(script); });

Product initializer IIFE হিসেবে সঙ্গে সঙ্গে চলে। বারবার AJAX navigation-এ duplicate event handler আটকাতে পুরোনো AbortController abort করা হয়:

if (window.productPageEventController) window.productPageEventController.abort();
window.productPageEventController = new AbortController();
const signal = window.productPageEventController.signal;
document.addEventListener('click', handler, { signal });

Gallery methods প্রতিবার current DOM element query করে; removed পুরোনো modal-এর reference ধরে রাখে না। Edit JSON GET request-এ cache:false দেওয়া আছে।

১১. Nuxt frontend dynamic faceted filter

বর্তমান অবস্থা: Product detail API variant-ready। কিন্তু listing/{url}-এ facet counts ও query-parameter filtering এখনো implement করা হয়নি। নিচের অংশটি পরবর্তী implementation blueprint—complete হয়েছে বলে ধরে নেবেন না।

Recommended request

GET /api/listing/men?attributes[1][]=4&attributes[2][]=9&sort=price_asc&page=1

একই Attribute-এর multiple values OR হবে (M অথবা L), আলাদা Attributes AND হবে (Size L এবং Color Black)।

foreach ($selectedAttributes as $attributeId => $valueIds) {
    $products->whereHas('variants', function ($variant) use ($attributeId, $valueIds) {
        $variant->where('status', true)
            ->whereHas('values', fn ($value) => $value
                ->where('attribute_values.attribute_id', $attributeId)
                ->whereIn('attribute_values.id', $valueIds));
    });
}

Filter response

  "slug": "size",

Filters কেবল selected category-এর is_filterable=true attributes থেকে আসবে। Value count category-এর active products এবং active variants থেকে COUNT(DISTINCT products.id) দিয়ে গণনা করা উচিত। Query string ব্যবহার করলে link share, browser back এবং SSR ঠিক থাকে।
