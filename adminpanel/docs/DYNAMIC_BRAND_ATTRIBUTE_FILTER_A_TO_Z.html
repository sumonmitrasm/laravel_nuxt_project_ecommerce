3. Brand filter: backend

URL থেকে IDs নিরাপদভাবে নেওয়া

private function selectedBrandIds(Request $request): array
{
    $brands = $request->query('brand', '');
    $brands = is_array($brands)
        ? $brands
        : explode(',', (string) $brands);

    return collect($brands)
        ->map(fn ($brandId) =>
            filter_var($brandId, FILTER_VALIDATE_INT)
        )
        ->filter(fn ($brandId) =>
            $brandId !== false && $brandId > 0
        )
        ->unique()
        ->take(50)
        ->values()
        ->all();
}

এতে invalid text, negative ID ও duplicate বাদ যায়। Maximum ৫০টি ID query abuse সীমিত করে।

Product query-তে Brand apply

Brand::query()

    ->join('products', 'products.brand_id', '=', 'brands.id')

4. Attribute filter: backend

Category-এর filterable Attributes নির্ধারণ

private function filterableAttributeIds(int $categoryId): array
{
    $visited = [];

    while ($categoryId && ! in_array($categoryId, $visited, true)) {
        $visited[] = $categoryId;

        $rows = DB::table('category_attribute')
            ->where('category_id', $categoryId)
            ->orderBy('position')
            ->get(['attribute_id', 'is_filterable']);

        if ($rows->isNotEmpty()) {
            return $rows
                ->where('is_filterable', true)
                ->pluck('attribute_id')
                ->map(fn ($id) => (int) $id)
                ->values()
                ->all();
        }

        $categoryId = (int) Category::whereKey($categoryId)
            ->value('parent_id');
    }

    return [];
}

Current category-এর mapping না থাকলে parent mapping inherit হয়। Mapping থাকলে শুধু সেখানকার is_filterable Attributes নেওয়া হয়।

Selected value IDs validate এবং attribute অনুযায়ী group

private function selectedAttributeValueGroups(
    Request $request,
    array $filterableAttributeIds
): array {
    $values = $request->query('attribute', '');
    $values = is_array($values)
        ? $values
        : explode(',', (string) $values);

    $valueIds = collect($values)
        ->map(fn ($id) => filter_var($id, FILTER_VALIDATE_INT))
        ->filter(fn ($id) => $id !== false && $id > 0)
        ->unique()
        ->take(100)
        ->values();

    return ProductAttributeValue::query()
        ->whereIn('id', $valueIds)
        ->whereIn('attribute_id', $filterableAttributeIds)
        ->where('status', true)
        ->get(['id', 'attribute_id'])
        ->groupBy('attribute_id')
        ->map(fn ($values) =>
            $values->pluck('id')->map(fn ($id) => (int) $id)->all()
        )
        ->all();
}

OR এবং AND rule

ধরুন selected values:

Color: [Red, Blue]
Size:  [XL]

Business condition:

(Color = Red OR Color = Blue) AND (Size = XL)

একই Variant-এর মধ্যে combination নিশ্চিত করার query:

$query->whereHas('variants', function ($variant) use ($groups) {
    $variant->where('status', true);

    foreach ($groups as $valueIds) {
        $variant->whereHas(
            'values',
            fn ($value) =>
                $value->whereIn('attribute_values.id', $valueIds)
        );
    }
});
Outer whereHas('variants') একবার হওয়ায় Red variant এবং অন্য XL variant ভুলভাবে এক Product match করায় না। একটি active Variant-এই সব selected attribute groups মিলতে হয়।

Available Attribute facets query

DB::table('attributes as attribute')
    ->join('attribute_values as value',
        'value.attribute_id', '=', 'attribute.id')
    ->join('attribute_value_product_variant as pivot',
        'pivot.attribute_value_id', '=', 'value.id')
    ->join('product_variants as variant',
        'variant.id', '=', 'pivot.product_variant_id')
    ->join('products as product',
        'product.id', '=', 'variant.product_id')
    ->whereIn('attribute.id', $attributeIds)
    ->whereIn('product.category_id', $categoryIds)
    ->where('attribute.status', true)
    ->where('value.status', true)
    ->where('variant.status', true)
    ->where('product.status', true)
    ->groupBy(/* attribute and value columns */)
    ->get([
        'attribute.id as attribute_id',
        'attribute.name as attribute_name',
        'attribute.slug as attribute_slug',
        'attribute.type as attribute_type',
        'value.id as value_id',
        'value.value',
        'value.color_code',
        DB::raw('COUNT(DISTINCT product.id) as product_count'),
    ]);

const selectedBrandIds = computed(() => {
  const value = Array.isArray(route.query.brand)
    ? route.query.brand.join(',')

    .map(id => Number.parseInt(id, 10))

8. Security rules

  • URL IDs secret নয়; backend-এ integer validation আবশ্যক।
  • Selected value অবশ্যই current category-এর filterable Attribute-এর হতে হবে।
  • whereIn()/Query Builder parameter binding ব্যবহার করুন; raw input SQL string-এ বসাবেন না।
  • Request IDs limit করুন: Brand ৫০, Attribute values ১০০।
  • Only active Product, Brand, Variant, Attribute ও value query করুন।
  • Private inventory/admin endpoint-এ authorization আলাদাভাবে লাগবে; public catalog filter public data।
Slug ব্যবহার করলে URL সুন্দর হয়, কিন্তু ID-এর চেয়ে বেশি secure হয় না। Security backend validation ও authorization থেকে আসে।

9. Performance rules

  • Products paginate করুন; সব products এক response-এ পাঠাবেন না।
  • Facet query-তে COUNT(DISTINCT product.id) ব্যবহার করুন।
  • Existing indexes রাখুন: products(category_id), products(brand_id), product_variants(product_id,status), pivot primary key এবং category_attribute(category_id,is_filterable)।
  • Facet result cache করুন; paginated live product results indiscriminately cache করবেন না—price/stock stale হতে পারে ও cache-key explosion হয়।
  • Nuxt filter change-এ old grid retain করুন; full-page loader দেবেন না।

12. এখনো implement হয়নি

বর্তমান UI-এর Category/Subcategory, Price এবং Customer Rating sections-এর static markup আলাদা বিষয়। এই document-এর working implementation হলো Brand + dynamic Attributes।
