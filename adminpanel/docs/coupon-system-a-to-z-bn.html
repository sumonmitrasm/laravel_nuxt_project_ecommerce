১. System overview

Coupon apply করা মানে coupon ব্যবহৃত হয়ে গেছে—এটি নয়। Apply করলে coupon কেবল cart-এ সাময়িকভাবে যুক্ত হয় এবং প্রতিবার total দেখানোর সময় server আবার rules যাচাই করে। Payment/order সফল হলে তবেই coupon_usages-এ স্থায়ী usage record হবে।

Admin creates coupon→User enters code→Server validates→Cart stores coupon_id→Server calculates total→Order transaction records usage
মূল নীতি: browser কখনো discount amount নির্ধারণ করবে না। Laravel product price, eligible subtotal এবং final discount পুনরায় হিসাব করবে।

গুরুত্বপূর্ণ columns

  • scope: all/products/categories/brands
  • customer_scope: all/selected/first_order/lifetime_spend
  • discount_type: fixed/percentage/free_shipping
  • minimum_order_amount: cart subtotal-এর সর্বনিম্ন সীমা
  • maximum_discount: percentage coupon-এর সর্বোচ্চ ছাড়
  • usage_limit: সব customer মিলিয়ে limit
  • usage_limit_per_user: একজন customer-এর limit
  • starts_at/expires_at: campaign সময়
  • exclude_discounted_products: আগে থেকেই discounted item বাদ

৪. প্রয়োজনীয় migration pattern

Schema::create('coupon_usages', function (Blueprint $table) {
    $table->id();
    $table->foreignId('coupon_id')->constrained()->cascadeOnDelete();
    $table->foreignId('user_id')->nullable()->constrained()->nullOnDelete();
    $table->uuid('guest_token')->nullable();
    $table->decimal('discount_amount', 12, 2);
    $table->timestamp('used_at');
    $table->timestamps();
    $table->index(['coupon_id', 'user_id']);
    $table->index(['coupon_id', 'guest_token']);
});

Schema::table('carts', function (Blueprint $table) {
    $table->foreignId('coupon_id')->nullable()->constrained()->nullOnDelete();
    $table->timestamp('coupon_applied_at')->nullable();
});

Save করার মূল অংশ

DB::transaction(function () use ($coupon, $data, $relations) {
    $coupon->fill($data);
    if (! $coupon->exists) $coupon->created_by_id = Auth::guard('admin')->id();
    $coupon->save();

    $coupon->products()->sync($coupon->scope === 'products' ? $relations['products'] : []);
    $coupon->categories()->sync($coupon->scope === 'categories' ? $relations['categories'] : []);
    $coupon->brands()->sync($coupon->scope === 'brands' ? $relations['brands'] : []);
    $coupon->users()->sync($coupon->customer_scope === 'selected' ? $relations['users'] : []);
});

Transaction ব্যবহারে coupon save হলেও pivot ব্যর্থ—এমন অর্ধেক data থাকবে না। Code save করার আগে uppercase করা হয়, তাই welcome1 এবং WELCOME1 একইভাবে পরিচালিত হয়।

৭. CouponService: business rules

Controller পাতলা রাখা হয়েছে; coupon-এর নিয়ম একটি service-এ। Calculation-এর ক্রম:

  1. Active, start/end date এবং global limit
  2. Customer eligibility এবং per-user limit
  3. Minimum order
  4. Eligible items নির্বাচন
  5. Fixed/percentage/free-shipping calculation
  6. Maximum discount cap
$discount = match ($coupon->discount_type) {
    'fixed' => min((float) $coupon->discount_value, $eligibleSubtotal),
    'percentage' => $eligibleSubtotal * ((float) $coupon->discount_value / 100),
    'free_shipping' => 0,
    default => 0,
};

if ($coupon->discount_type === 'percentage' && $coupon->maximum_discount !== null) {
    $discount = min($discount, (float) $coupon->maximum_discount);
}
উদাহরণ: eligible subtotal ৳10,000, discount 20%, maximum discount ৳1,500 হলে raw discount ৳2,000 হলেও final discount ৳1,500। Fixed ৳500 coupon-এর eligible subtotal ৳300 হলে discount ৳300—total কখনো negative হবে না।

Product scope

all হলে সব cart item; products হলে pivot product ID; categories হলে product-এর category ID; brands হলে brand ID match করা হয়। exclude_discounted_products=true হলে discounted item আগে বাদ যায়।

১০. সম্পূর্ণ request flow

  1. User code লিখে Apply চাপেন।
  2. Nuxt CSRF cookie নেয় এবং POST /api/cart/coupon পাঠায়।
  3. CartManager guest হলে token, login হলে user_id দিয়ে cart নেয়।
  4. Controller uppercase code দিয়ে coupon খোঁজে।
  5. Coupon ID cart-এ সাময়িকভাবে save হয়।
  6. cartPayload() database price থেকে items/subtotal বানায়।
  7. CouponService rules যাচাই ও discount হিসাব করে।
  8. ব্যর্থ হলে coupon cart থেকে সরিয়ে 422 error দেয়।
  9. সফল হলে updated cart response Nuxt state-এ যায়।
  10. Reload-এ cart-এর coupon ID থেকে আবার validation/calculation হয়।
  11. Order সফল হলে order snapshot এবং coupon usage একই DB transaction-এ save হয়।

১১. Place Order integration — অবশ্যই করতে হবে

বর্তমান project status: checkout UI ও coupon apply আছে, কিন্তু real order placement/usage insert এখনও সংযুক্ত নয়। তাই এখন Apply করলে carts update হয়; coupon_usages update হওয়া উচিত নয়।

Production implementation-এ transaction-এর ভিতর cart lock করে server-side total পুনরায় calculate করুন:

DB::transaction(function () use ($request) {
    $cart = Cart::where('user_id', $request->user()->id)
        ->lockForUpdate()->firstOrFail();

    $payload = $this->cartPayload($cart, $request, true); // revalidate coupon

    $order = Order::create([
        'user_id' => $request->user()->id,
        'subtotal' => $payload['summary']['subtotal'],
        'coupon_id' => $payload['coupon']['id'] ?? null,
        'coupon_code' => $payload['coupon']['code'] ?? null, // snapshot recommended
        'discount_amount' => $payload['summary']['discount'],
        'shipping_amount' => $serverShipping,
        'grand_total' => max(0, $payload['summary']['subtotal']
            - $payload['summary']['discount'] + $serverShipping),
    ]);

    // Create order_items here using server prices.
    if ($cart->coupon_id) {
        CouponUsage::create([
            'coupon_id' => $cart->coupon_id,
            'user_id' => $request->user()->id,
            'guest_token' => $cart->guest_token,
            'discount_amount' => $payload['summary']['discount'],
            'used_at' => now(),
        ]);
    }
    $cart->items()->delete();
    $cart->delete();
});

Payment gateway থাকলে usage কখন লিখবেন তা payment model-এর উপর নির্ভর করে: COD-তে confirmed order creation; online payment-এ verified payment success/webhook। Failed/cancelled attempt usage নয়।

First order: production-এ শুধু CouponUsage নয়, confirmed/paid orders count যাচাই করা বেশি নির্ভরযোগ্য। অন্য coupon আগে ব্যবহার করেছে মানেই সবসময় order করেছে—এমন নয়; usage অবশ্য order success-এ লিখলে এই সমস্যা কমে।

১২. Security rules

  • Frontend subtotal/discount/total গ্রহণ করবেন না; server price ব্যবহার করুন।
  • Authenticated cart lookup-এর প্রথম শর্ত user_id; token authentication নয়।
  • Guest cart query-তে whereNull('user_id') দিন, যাতে token leak হলেও logged-in cart guest হিসেবে না পাওয়া যায়।
  • Apply/remove POST/DELETE হওয়ায় CSRF protection রাখুন।
  • Code endpoint-এ throttle যোগ করা যায়, যেমন throttle:20,1, brute-force code guessing কমাতে।
  • Order transaction-এ coupon row/cart row lock এবং limit পুনরায় check করুন, simultaneous checkout race ঠেকাতে।
  • Money-এর জন্য decimal ব্যবহার করুন; float শুধু display/intermediate হলে শেষে round করুন।
  • Admin routes permission middleware-এর ভিতরে রাখুন।
  • Error message অতিরিক্ত internal data প্রকাশ করবে না।

১৫. Common errors ও diagnosis

  • “not available yet”: starts_at server timezone-এর ভবিষ্যতে। App/database timezone মিলান।
  • First order কাজ করছে না: usage কখন লেখা হচ্ছে দেখুন; Apply-এর সময় লেখা ভুল, successful order-এর সময় লিখুন।
  • Reload-এ coupon চলে যায়: cart resolver একই cart পাচ্ছে কি না এবং coupon_id fillable/relation আছে কি না দেখুন।
  • Wrong discount: eligible subtotal বনাম whole subtotal log/test করুন।
  • coupon_users নিয়ে confusion: এটি selected-customer permission; ব্যবহারের record coupon_usages।
  • Guest/login mismatch: login-এর সময় guest cart-এ user_id বসছে এবং token retained আছে কি না দেখুন।
  • Encoding-এ ৳ ভাঙা: source/database/response UTF-8 এবং HTML <meta charset="utf-8"> নিশ্চিত করুন।

শেষ কথা: CouponService নিয়ম নির্ধারণ করে, CartController apply/recalculate করে, carts সাময়িক selection রাখে, এবং successful Order transaction স্থায়ী coupon usage লেখে—এই চারটি দায়িত্ব আলাদা রাখলেই system বোঝা ও অন্য project-এ নেওয়া সহজ হয়।
